# Automatic-Water-Dispenser
This personal project is an Arduino-based automatic water dispenser. The embedded system waits for the user to press a button once the water bottle is placed. When the button is pressed, the servo motor presses down on the dispensing button. The ultrasonic sensor detects the water level every 110ms. Once the sensor reads that the distance is less than or equal to 4cm twice, it'll release the servo motor, causing the dispenser to stop dispensing water. I've also added an emergency stop feature that stops when the user types space in the Serial Monitor to prevent spills.

In the future, I plan to add CV to detect the presence of a water bottle and dispense without user input, upgrade the chassis using CAD/3D printing, and add other miscellaneous features.
